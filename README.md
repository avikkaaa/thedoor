# DOOR

**Finally, a smarter way to use a door.**

A deliberately useless UI/UX challenge project: an absurdly over-engineered digital ecosystem for opening, closing, locking, unlocking, analyzing, reviewing, customizing, and worrying about a door.

## Tech
- Vite
- HTML
- CSS
- Vanilla JavaScript

## Run locally

```bash
npm install
npm run dev
```

Vite will print a local development URL in the terminal.

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/`.

## Deploy on Vercel

Import the GitHub repository into Vercel.

Vercel should automatically detect **Vite**. If needed, use:

- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`
