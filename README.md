# DOOR

A Vite-based interactive UI/UX project built around an intentionally over-engineered door experience.

## Features

- Open, close, lock, and unlock interactions
- Realistic recorded door, latch, lock, and unlock sounds
- Multiple door types
- Door material and handle customization
- Live customization preview
- Adjustable opening speed
- Door analytics and performance metrics
- Door Emergency Center
- Achievements and Door AI
- Color / full-grayscale theme toggle
- Responsive layout

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy on Vercel

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
